2 Create Your First Instance

⏱️ Estimated time: 2 minutes

An instance is your isolated workspace for a single app. It connects the Application Zone to your CaseWright runtime and loads all available agents from the manifest.

What happens at this stage:

  • You provide instance configuration (name, app ID, runtime URL)
  • Application Zone backend loads the manifest
  • All 6 agents are discovered and ready to use
  • Instance is saved with your configuration
💡 Tip: If you don't have CaseWright running yet, you can still create the instance. The runtime connection can be added later.
Sub-stages at this level:
Fill instance form (name, app ID)
Provide runtime URL (optional)
Click "Create Instance"
See success message + agent count
