# Green Remediation Planner AgentPack certification

## Status

`candidate-agent-pack`

## Summary

Drafts hardening guidance, remediation plans, runbook updates, and optional pull requests for human review.

## Required evidence before promotion

- Draft-only remediation contract.
- Human-review-required policy.
- Rollback guidance.
- Audit trail for generated artifacts.
- Tests proving no automatic merge or production deployment.

## Certification note

This AgentPack can create draft artifacts but must not merge pull requests or deploy changes without named-human approval.
