# Microsoft Agent Framework SDK - canonical pin list.
#
# DO NOT copy these into a project's requirements.txt as hard pins. The
# packages are preview (rc/beta) and install-order-sensitive: the
# azure-ai-agentserver-* packages pin agent-framework-core<=rc3, so the
# rc6 agent-framework packages MUST be installed AFTER the agentserver
# packages for rc6 to win resolution.
#
# Use the helper scripts to install in the correct order:
#   Windows : scripts/install_agent_framework.ps1
#   Linux   : scripts/install_agent_framework.sh
#
# The list below is the authoritative version set as of this template's
# last update. Projects should paste these as commented-out references
# in their own requirements.txt so the pin set is discoverable without
# being auto-installed.
