# How To View Detailed Architecture Diagrams (Windows)

This guide is for new users who want to open detailed architecture diagram files (`.drawio`) generated by the factory.

## What You Are Opening

A detailed architecture file is a Draw.io diagram with multiple pages, for example:

- Logical architecture
- Sequence flows
- Failure paths

Project-scoped example:

- `projects/field-service-intelligence-platform-20260415212450/diagrams/field-service-intelligence-platform-20260415212450-detailed-architecture.drawio`

## Option 1 (Recommended): Open In VS Code

Use this if you already use VS Code.

1. In File Explorer, right-click the `.drawio` file.
2. Select **Open with** -> **Visual Studio Code**.
3. If prompted, install a Draw.io extension (for example, Draw.io Integration).
4. Open the file again. You should see the rendered diagram.
5. Use the page selector to switch between pages.

## Option 2: Open In draw.io Desktop App

Use this if you want a dedicated desktop viewer/editor.

1. Install draw.io Desktop from diagrams.net.
2. Launch the app.
3. Select **File** -> **Open**.
4. Pick your `.drawio` file.
5. Use the page tabs/dropdown to navigate diagram pages.

## Option 3: Open In Browser (No Install)

Use diagrams.net web app.

1. Go to `https://app.diagrams.net/`.
2. Choose **Open Existing Diagram**.
3. Choose **Device**.
4. Select your `.drawio` file.

## Option 4: Open Through Local Factory Portal URL

If the local portal server is running (`scripts/start_factory_portal.py`), you can open the diagram over HTTP.

Project-scoped example URL:

- `http://localhost:5501/projects/field-service-intelligence-platform-20260415212450/diagrams/field-service-intelligence-platform-20260415212450-detailed-architecture.drawio`

## Troubleshooting

## Error: "File not found"

Possible causes:

1. The URL path is wrong.
2. The local portal server is not running.
3. A wrapper viewer cannot reach your local `localhost` endpoint.

Fixes:

1. Verify the file exists in the repo path first.
2. Start the portal server and retry the local URL.
3. Open the raw file directly in VS Code or draw.io Desktop.
4. If using diagrams.net web, use **Open Existing Diagram -> Device** instead of remote URL.

## Error: "Guide Me only shows prompt to paste in VS Code"

This means the new menu script did not load and the portal used the legacy fallback.

Fixes:

1. Hard refresh the portal page (`Ctrl+F5`).
2. Confirm script URL loads in browser:
   - `http://localhost:5501/assets/portal/guide_me_menu.js`

## Quick Validation Commands (PowerShell)

Run from repository root:

```powershell
Test-Path .\projects\field-service-intelligence-platform-20260415212450\diagrams\field-service-intelligence-platform-20260415212450-detailed-architecture.drawio
try { (Invoke-WebRequest -UseBasicParsing http://localhost:5501/health -TimeoutSec 3).StatusCode } catch { $_.Exception.Message }
try { (Invoke-WebRequest -UseBasicParsing http://localhost:5501/projects/field-service-intelligence-platform-20260415212450/diagrams/field-service-intelligence-platform-20260415212450-detailed-architecture.drawio -TimeoutSec 5).StatusCode } catch { $_.Exception.Message }
```

Expected:

1. `Test-Path` returns `True`
2. Health endpoint returns `200`
3. Diagram URL returns `200`
