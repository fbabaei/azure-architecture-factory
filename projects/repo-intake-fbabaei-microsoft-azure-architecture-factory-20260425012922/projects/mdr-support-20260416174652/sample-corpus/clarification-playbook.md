# MDR Clarification Playbook

When a draft is incomplete, ask for the missing mandatory fields in a tight order: reference, summary, implementation date, hallmarks, parties, then jurisdictions.

If the uploaded material suggests a hallmark but does not state the code explicitly, ask a confirmation question instead of guessing.

If multiple jurisdictions appear in the evidence, ask which entities are established in each jurisdiction and which party is the reporting intermediary.

Store concise, auditable answers so the final arrangement record can be reviewed without replaying the entire conversation.
