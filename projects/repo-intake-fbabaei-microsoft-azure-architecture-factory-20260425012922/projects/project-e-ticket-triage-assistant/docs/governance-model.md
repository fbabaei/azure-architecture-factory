# AI/ML Governance Model

## Control Areas

- Identity: enforce least-privilege access and managed identities.
- Data Protection: encrypt ticket data in transit and at rest.
- Prompt and Model Safety: apply content filtering and evaluation gates.
- Auditability: keep traceable logs for routing and recommendation decisions.

## Review Cadence

- Weekly quality review for misrouted tickets.
- Monthly security and compliance checkpoint.
- Quarterly model and prompt re-baseline.
