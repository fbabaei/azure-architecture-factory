# MDR Support - Overview Diagram Notes

High-level view of the MDR support agent aligned to the updated design.

## Components
- **Tax Analyst** (browser) - uploads PDFs/text and drives clarification and case review.
- **Entra ID** - issues JWTs that APIM validates.
- **API Management** - public gateway with JWT validation and rate limiting.
- **MDR Agent API** (Container Apps) - FastAPI service in `src/mdr_agent/`.
- **Azure OpenAI** (`gpt-4o`) - extraction and MDR Q&A model responses.
- **Document Intelligence** - `prebuilt-layout` model for PDF text extraction.
- **Azure AI Search** (optional) - retrieval layer used to enrich Q&A context.
- **Blob Storage** - uploaded evidence/documents (including knowledge-base source files).
- **Cosmos DB** - case/session persistence (`arrangements`, `sessions`, `case-drafts`, `audit-log`).
- **Managed Identity** - workload identity for downstream Azure calls.
- **Key Vault** - secret and configuration reference store.
- **App Insights + Log Analytics** - traces, metrics, logs, and monitoring.

## API Surface (overview)
- Session lifecycle: `POST/GET/DELETE /api/session/{id}`
- Upload and extraction: `POST /arrangements/upload`, `POST /api/upload`, `POST /api/case/from-text`
- Conversation routing: `POST /api/chat` (`qa`, `clarification`, `off_topic` modes)
- Case lifecycle: `GET/PUT /api/case/{id}`, `POST /api/case/{id}/confirm`
