# AI/ML Governance Model

## Governance Controls
- Managed identity for service-to-service authentication
- Key Vault-backed secret management
- Least-privilege RBAC for runtime and deployment identities
- Application Insights and structured run logs for traceability
- Log Analytics workspace, health probes, and alert routing are part of the starter operating model
- Governance review checkpoint based on BRD security and compliance requirements

## Operating Cadence
- Review generated starter assets before production use
- Track deployment changes through version control and manifest updates
- Re-run BRD generation when requirements materially change
