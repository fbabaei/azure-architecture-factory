# AI/ML Governance Model

## Governance Controls

- Identity and access via Entra ID + RBAC
- Secrets and keys managed in Azure Key Vault
- End-to-end telemetry for prompts, responses, and system health
- Change management with versioned prompts/models and release approvals
- Responsible AI controls: content filtering, safety evaluation, and audit trail

## Operating Cadence

- Weekly quality and adoption review
- Monthly security/compliance checkpoint
- Quarterly model and prompt performance re-baseline
