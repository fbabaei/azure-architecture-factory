# Portal new-user UX plan

## Goal

Make the AI Factory Services portal approachable for first-time users while preserving advanced controls for experienced users.

## Phase 1: Start Here onboarding — implemented

- Add a Start Here panel near the top of the portal.
- Provide role-based entry cards for CSA users, architects, agent builders, and app/agent-pack validators.
- Provide guided examples for CaseWright, Supply Chain Control Tower, and AI Security Control Tower.
- Keep advanced portal sections available but avoid making new users parse them first.

## Phase 2: First-time user mode — implemented

- Add a simplified first-run view with the User Map, Start Here cards, recommended next action, and latest projects.
- Add a visible "Show advanced controls" option.
- Keep dense operational and certification evidence collapsed by default.

## Phase 3: Hero and workflow clarity — implemented

- Tighten the hero value proposition.
- Add primary action buttons that route to architecture planning, agent exploration, and Apps & Agents catalog validation.
- Add short "what happens next" copy for each major workflow.

## Phase 4: Guided examples and demo mode — implemented

- Add one-click example paths:
  - Try CaseWright.
  - Review Supply Chain Control Tower.
  - Explore Security Control Tower.
- Add sample BRD/demo project actions so a new user can see a useful result quickly.

## Phase 5: Progress indicators — implemented

- Add workflow progress indicators for BRD intake, architecture generation, deployment readiness, and app/agent-pack validation.
- Show "where am I?" and "what does done look like?" guidance.

## Phase 6: Catalog scanability — implemented

- Add filters/search and stronger badges:
  - Certified.
  - Preview.
  - Needs setup.
  - Local test.
  - Production-pilot gated.
- Keep long evidence and governance content behind expandable details.

## Phase 7: Contextual help — implemented

- Add short "What can I do here?" help blocks per major tab.
- Prefer outcome language over internal platform terms.

## Phase 8: Environment clarity — implemented

- Make local, deployed preview, certification-ready, and production-pilot-gated states explicit across the UI.
- Reinforce that local Quick Launch is a test harness, not a production deployment path.
